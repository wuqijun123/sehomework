# VP Lab 界面约定

使用官方 Vben Admin 的 Ant Design Vue 布局，保留侧栏、面包屑和多页签行为。后续页面沿用组件规范，不另做一套导航。

- 颜色：白色面板、浅灰工作区、蓝色主要操作；红绿仅表达状态。
- 字体：系统无衬线，中文使用 PingFang SC / Microsoft YaHei；正文 14px，辅助信息 12–13px，页面标题 20px，模块标题 16px。
- 间距：页面边距 20px，面板内边距 24px，窄屏 16px；面板间距 20px。
- 表格：浅灰表头、轻分隔线，操作列位置固定，长标题允许截断但保留完整提示。
- 页面标题左对齐，说明置于标题下方，主要操作置于同一行右侧。
- 空状态提供具体下一步，不使用虚构统计、装饰图表或营销文案。
- 图标使用本地 Lucide 组件，禁止依赖运行时远程图标请求。

构建与维护入口见 ../frontend/VPLAB.md。
